# Chrome Web Store listing

**Name**: 推广之手 · x-hands

**Summary** (≤132 chars):
在 X 上发帖时，一只手伸出来让你点「推广」，另一只手一巴掌把它打飞。

**Category**: Fun（娱乐）
**Language**: 中文（简体）

**Description**:
在 X（Twitter）上发帖时，一只西装手会伸出来，指着「推广」按钮连戳三下——然后另一只手冲进来，一巴掌把它连同「推广」一起打飞。

· 在发帖框里打几个字、停顿一下即触发，每个发帖框只演一次
· 点工具栏图标可以再看一遍
· 中文页面显示「推广 / 啪！」，其他语言显示「Promote / SLAP!」
· 不申请任何权限，不收集任何数据，不读取或修改你的帖子

开源：https://github.com/yetone/x-hands
本插件与 X Corp. 无关。

**Single purpose**:
Plays a short comedic animation over the X (Twitter) post composer: a hand points at a "Promote" button and another hand slaps it away.

**Permission justification**:
- Host access (content script on x.com / twitter.com): needed to detect when the user is typing in the post composer and to draw the animation on top of that page. No data is read, stored or sent.

**Remote code**: No.
**Data usage**: collects no user data.
**Privacy policy URL**: https://github.com/yetone/x-hands/blob/main/PRIVACY.md

**Assets**: `icon-128.png`, `screenshot-1..3.png` (1280×800), `promo-440x280.png`
